デスクトップちびフレンド v0.4.1
================================

Windows 11用・完全オフラインのデスクトップマスコットです。
ちび堕ふるが歩く、走る、座る、足をぱたぱたする、眠る、歌う、掘る、
窓をよじ登る、窓の上縁に座る、転ぶ、落ちるなどの行動をします。

【起動】
DesktopChibiFriend.exe をダブルクリックしてください。
初期設定ではWindowsへのサインイン時にも自動起動します。
終了は設定画面の「アプリを終了」から行います。

【基本操作】
・ちび堕ふるを左クリック：つんつんする／アピールを止める
・体を左ボタンでつまんで移動：つかむ。離す速さで投げる
・頭の上で左ボタンを押したまま小さく左右に動かす：なでる
・ちび堕ふるを右クリック：設定画面を開く
・デスクトップの何もない場所を右ダブルクリック：
  所持している呼び出しアイテムをランダムに出す
  （前の呼び出しアイテムは消えます）

【ちび堕ふるの行動】
・画面下部、小さなウィンドウ、通常ウィンドウを足場として歩きます。
・ウィンドウの端では、つかんで登るか、ぶつかって落ちます。
  ドジっ子なので、落ちる確率は登るより高めです。
・上まで登れても、そのまま座れるか落ちるかは半々です。
・画面外へ落ちた場合、メインモニターの中央上から落下姿勢で戻ります。
・隣のモニターへ移るときは端へ飛び込み、隣側へ降ります。
・全画面表示またはゲームの画面には居座りません。
・OBSが起動するとデスクトップ本体は休み、OBS終了後に戻ります。
・5分以内に10回つんつんすると怒って洞窟へ帰ります。

【コインと所持品】
・コインは上から落ち、初期設定では15～30分に1枚出ます。
・出現間隔は1～60分の範囲で、最短と最長を設定できます。
・1時間拾われなかったコインは消えます。
・ちび堕ふるが触れると拾い、枚数へ追加します。
・掘っていると、ごくまれにコインを見つけます。
・コインが10枚以上あると、5枚で未所持品を優先して買いに行きます。
・装飾品、お菓子、おもちゃの3系統、全15種類です。
・設定画面で取得済みの品と所持数を確認できます。未取得品は「？」です。
・ユーザーがアイテムやコインを動かすことはできますが、直接取得はしません。

設定画面の「活動量」で、しずか／ふつう／にぎやかを変更できます。

【おしゃべり】
・定型文と、明日使えない豆知識をランダムに話します。
・まれに一瞬信じそうな嘘を「……たぶん」付きで話します。
・吹き出しはクリックで消えます。
・通常のおしゃべりでは、たまに吹き出しを放物線状に投げます。
・自動では文章2文字につき1秒、最低3秒表示します。
・政治、宗教、下ネタに関する発言は入れていません。

【ポモドーロ】
・初期値は集中25分、休憩5分、4ループです。
・設定画面から開始／途中終了できます。
・時間になると「おわり！！」と跳ねて強く知らせます。
・ちび堕ふるをクリックするとアピールが止まります。
・全画面表示になった時点でポモドーロは終了します。

【時計・アラーム】
・毎時0分に「○時だよ！」と知らせます。
・HH:MM形式の1回限りのアラームを1件設定できます。
・スヌーズはありません。鳴った後は自動的に無効になります。
・OBS中は音を鳴らしません。
・ゲーム中は画面上の表示で知らせ、クリックすると消えます。

【ダイス】
設定画面から 1d3 / 1d4 / 1d6 / 1d10 / 1d20 / 1d100 を振れます。
移動中でも立ち止まり、ダイスを持ち上げて結果を見せます。履歴は残しません。

【OBS配信】
OBSを起動すると本体が自動的に休みます。
OBSの「ブラウザ」ソースへ、設定画面に表示されるURLを入力してください。
初期URL： http://127.0.0.1:47831/
背景は透過され、簡易版のちび堕ふるとコインだけが表示されます。
外部通信は行わず、このPC内だけで動作します。

【設定・保存】
settings.json と profile.json はアプリの data フォルダに作成されます。
設定、コイン、所持品、最後の位置を引き継ぎます。
配布用ZIPには個人の保存データを含めないでください。

【軽量版について】
v0.4.1は.NET/WPFを使わないネイティブ版です。
キャラ・コイン・アイテムの周囲だけに小さな透過ウィンドウを作り、
表示中のアニメーションだけを読み込むことで常駐メモリを抑えています。

【困ったとき】
・見えない：タスクトレイのアイコンから設定を開き、OBSや全画面を終了してください。
・右ダブルクリックが効かない：デスクトップアイコンやウィンドウ上を避けてください。
・画像がない：charactersフォルダをexeと同じ場所に置いてください。
・ログ：DesktopChibiFriend.log を確認してください。

対応OS：Windows 11
音声・BGM：なし（通知用の効果音のみ）
通信：不要。完全オフライン動作
